# 🔥 DevPulse — GitHub Activity Intelligence Dashboard

DevPulse is a full-stack, production-quality dashboard that takes a GitHub username and generates a beautiful visual breakdown of their developer activity, language usage, repo health scores, and an AI-generated "Developer Personality" report.

## 🚀 Features
- **Visual GitHub Activity Breakdown**
- **Contribution Heatmaps**
- **Language Usage Charts**
- **Repository Health Scores**
- **AI-Powered "Developer Personality" Report (Gemini AI)**

## 🛠️ Tech Stack
- **Frontend**: React (Vite), Tailwind CSS, Chart.js, Framer Motion
- **Backend**: Node.js, Express, MongoDB
- **APIs**: GitHub REST API, Google Gemini AI API
